# AgentWriter-AI

# How to run?

1. Clone the repository to your local machine.

```bash 
git clone https://github.com/anjisake71-collab/AgentWriter-AI.git
``` 

2. Navigate to the project directory 

```bash

cd AgentWriter-AI
```

3. create a virtual environment (optinal but recommended).

```bash
conda create -n agentwriter python-3.11 -y
```

4. Activate the virtual environment.

```bash
conda activate agentwriter
```

5.Install the required dependencies.

```bash
pip install -r requirements.txt
```
6. Run the application.

```bash
python app.py
```
